Command to run application: **Docker compose up**

**Technology Stack** \
**Odoo :** Odoo is preferred because it provides a unified ERP platform with built-in ORM, workflows, security and UI components. This reduces integration complexity, speeds development, centralizes business logic and lowers maintenance effort compared to managing multiple external systems. External services are still useful for highly scalable or compute-intensive workloads.

**Models of our aircraft maintanence application** \
**Aircraft :** Manage Aircraft operations \
**Component :** Manages Many component for the individual aircraft \
**Finding :** Maintain aircraft with the technical log entry \
**Flight log :** Insert flight logs while updating components \
**Installation :** Maintaining component installation and uninstallation history \
